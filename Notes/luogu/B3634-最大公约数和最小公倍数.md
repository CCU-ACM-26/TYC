# 洛谷 B3634 最大公约数和最小公倍数 题解

## 1. 题目描述
给定两个正整数 \(a, b\)，求它们的最大公约数（GCD）和最小公倍数（LCM）。这两个整数 \(a, b\) 均在 `int` 范围内。

**输入格式：** 两个整数 \(a\) 和 \(b\)，用空格分隔。
**输出格式：** 两个整数表示答案，用空格隔开。

---

## 2. 核心算法：辗转相除法

### 2.1 最大公约数（GCD）
使用**欧几里得算法（辗转相除法）**。
**原理**：两个数的最大公约数，等于较小的数与两数相除余数的最大公约数。
**公式**：`gcd(a, b) = gcd(b, a % b)`，当余数为 0 时，除数即为最大公约数。

> **tips**：如果 `a < b`，代码不需要手动交换，`a % b` 在第一轮会自动将 `a` 和 `b` 互换。

### 2.2 最小公倍数（LCM）
**公式**：\(LCM(a, b) = \frac{a \times b}{GCD(a, b)}\)
**安全写法**：`a / gcd(a, b) * b` （先除后乘防溢出）也可a*b/gcd

---

## 3.  AC 代码 (C++)

```cpp
#include <bits/stdc++.h>
using namespace std;

// 手写辗转相除法（欧几里得算法）
long long gc(long long a, long long b) {
    while (b != 0) {
        long long temp = a % b;
        a = b;
        b = temp;
    }
    return a;
}

int main() {
    // 【关键点1】使用 long long 防止计算过程中数据溢出
    long long a, b;
    cin >> a >> b;
    
    // 1. 求最大公约数
    long long g = gc(a, b);
    
    // 2. 求最小公倍数
    // 【关键点2】必须先除后乘：a / g * b
    long long l = a * b /gc; 
    
    // 按格式输出
    cout << g << " " << l << endl;
    
    return 0;
}
